# 风电项目估值与风险审查

审查风电项目估值、现金流、融资与租赁风险。

## 安装

方式一（通过Hermes技能中心）：

```bash
hermes skills install https://raw.githubusercontent.com/x18815379395-wq/hermes-wind-power-project-valuation-risk-review/main/SKILL.md
```

方式二（手动安装，从GitHub克隆）：

```bash
git clone https://github.com/x18815379395-wq/hermes-wind-power-project-valuation-risk-review.git ~/.hermes/skills/financial-risk/wind-power-project-valuation-risk-review
hermes reload-skills
```

> 注意：`hermes skills install` 方式需要Hermes Agent支持从GitHub URL安装SKILL.md。若不支持，请使用手动克隆方式。

## 使用方法

覆盖风资源评估与发电量P50/P90置信度、上网电价与补贴政策、风电项目IRR/NPV/回收期估值、建设期与运营期现金流、风机技术选型与质保、用地合规与环评、融资租赁结构设计。

具体使用方法请参考技能的 `SKILL.md` 文件。
